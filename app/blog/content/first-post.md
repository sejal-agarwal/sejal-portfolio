Hello there, welcome to my new website and first blog post! As I have been navigating my life through graduate school and this crazy job market, I decided I wanted to start a blog to keep myself accountable learning about UI/UX design and frontend development. However, as I began to think about what things to write about in my blog, I decided that I didn't like my old website and should create a new one, and before creating my new website, I decided that it was time to formally learn how to use Figma to create UI mockups. So as you can tell... I spiralled a bit.

However, a month or so later, I finally did all of it! I watched a really great [Youtube video](https://www.youtube.com/watch?v=HZuk6Wkx_Eg) where I learned a lot about the basics of Figma and how to create a website mockup. Would 100% recommend anyone trying to learn how to use Figma. I then created my own mockup for my personal website based off of [this template](https://www.figma.com/community/file/1408441048826723944/bentolio-portfolio-design-template?q_id=f1b5ad6a-4ea9-4014-a56d-461a40f3c460) and created [this](https://www.figma.com/design/AHjDduqPlaGkCZewbpCpBk/Sejal-Portfolio-Design?node-id=0-1&t=kmW4xKSEIhdwQ3l5-1)! As you can see, the final website has a few differences but I'm happy with how it turned out!

![Figma mockup of the website homepage](/blog-images/figma-mockup-homepage.png)

I'm really excited with embarking on this journey to become a better developer, HCI resercher, and UI/UX designer. If you have somehow landed on this page and are reading this, thanks for being part of my journey <3.
